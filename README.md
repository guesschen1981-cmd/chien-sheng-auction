# 📦 線上拍賣倒數計時器 — 粉絲與賣家操作使用說明書

> 💡 **版本**：v2.0 雲端即時競標版　｜　**最後更新**：2026-10-16  
> 🌐 **技術棧**：純 HTML / CSS / JavaScript + Firebase Realtime Database  
> 💰 **費用**：完全免費（Firebase Spark 免費方案 + GitHub Pages / Vercel）

---

## 📖 簡介

本工具是一套完全採用「**跨裝置響應式網頁設計（RWD）**」打造的線上拍賣倒數計時系統。不論是用手機、平板還是電腦大螢幕瀏覽，都能獲得最佳化體驗。

### ✨ 核心功能一覽

| 功能 | 說明 |
|------|------|
| 📸 多圖拖曳上傳 | 支援批次拖曳多張本地圖片，即時預覽、封面選取、輪播瀏覽 |
| 🎬 影音嵌入 | 貼上 YouTube 連結自動解析並嵌入播放器 |
| ⏱️ 雙倒數模式 | 固定期限倒數 ＋ 24 小時滾動重置，附防壓標自動延長 |
| 🛡️ 防壓標機制 | 最後 N 分鐘有人出標自動延長，杜絕最後一秒壓標 |
| ☁️ 雲端即時同步 | Firebase Realtime Database，所有買家出標畫面即時同步 |
| 📲 QR Code 發布 | 一鍵生成可掃描 QR Code，貼至各大社群讓買家掃碼競標 |
| 🔍 資料驗證 | 發布前自動稽核所有欄位，錯誤處高亮提示並自動滾動定位 |
| 👁️ 買家視角預覽 | 發布前可模擬手機版 / 電腦版買家實際瀏覽頁面 |
| 💾 分區備份匯出 | 四大區塊各自獨立 JSON 備份，可隨時匯出還原 |
| 📱 手機優化 | 觸控按鈕加大、手勢滑動圖片、手機底部快捷出標列 |

## 🚀 第一步：免費雲端資料庫與連網部署（一次性設定）

> 若只在同一台裝置測試，可略過此步驟直接使用本機模式。  
> 若要讓粉絲透過 QR Code / 連結跨裝置即時競標，則**必須完成此步驟**。

### 1-1　申請 Google Firebase 免費即時資料庫

1. 前往 [Firebase Console](https://console.firebase.google.com/) 並以 **Google 帳號** 登入

2. 點擊「**建立專案**」，輸入專案名稱（例如：my-auction），依步驟完成建立

3. 進入專案後，點擊網頁圖示 **</>** 新增 Web 應用程式
   - 輸入應用程式暱稱（任意）
   - 點擊「**繼續前往主控台**」

4. 在左側選單點擊「**建構**」→「**Realtime Database**」
   - 點擊「**建立資料庫**」
   - 位置選擇：**asia-southeast1**（距台灣最近，延遲最低）
   - 安全性規則：先選「**以測試模式啟動**」（30 天內可讀寫）

5. 回到「**專案設定**」（齒輪圖示）→「**您的應用程式**」
   - 找到您剛建立的 Web 應用程式
   - 複製 irebaseConfig 區塊中的各項設定值

6. 在拍賣系統後台點擊頂列「**☁️ 雲端**」按鈕，填入以下欄位：

| Firebase 設定欄位 | 說明 | 範例值 |
|-------------------|------|--------|
| **API Key** | Firebase 存取金鑰 | AIzaSy... |
| **Auth Domain** | 驗證網域 | my-auction.firebaseapp.com |
| **Database URL** | 即時資料庫位址 | https://my-auction-default-rtdb.asia-southeast1.firebasedatabase.app |
| **Project ID** | 專案識別碼 | my-auction-12345 |
| **App ID** | 應用程式 ID | 1:123456789:web:abc... |

7. 點擊「**✅ 儲存並連線**」，看到「已連線 ✓」即設定成功

> 🔒 **安全說明**：設定值僅儲存在您的瀏覽器 localStorage，不會上傳至任何第三方伺服器。

## 🛠️ 第二步：賣家後台完整設定說明

開啟您的拍賣系統網址，進入後台管理頁面。共有四個獨立設定區塊（A / B / C / D），每個區塊都可獨立儲存、重置或匯出備份。

---

### 🅐 區塊 A：賣家 / 店鋪資訊

本區塊設定賣家身份識別資訊，顯示於拍賣頁面頂列與買家頁面。

#### 賣家 / 店鋪名稱

- 適用於：個人賣家、手作工作室（如「建生工坊」）、品牌帳號或公司行號
- 此名稱將顯示在拍賣頁的 Nav Bar 品牌欄位

#### Logo 圖片上傳

1. 將品牌 Logo 圖片**拖曳**至上傳框，或點擊框內任意位置**開啟資料夾**選取
2. 支援格式：JPG / PNG / GIF / WebP（建議使用正方形圖片）
3. 上傳完成後即時顯示預覽
4. 點擊「**換圖**」可重新選擇；點擊「**刪除**」可移除

---

### 🅑 區塊 B：商品資訊與多媒體上傳

#### 文字資訊

| 欄位 | 是否必填 | 說明 |
|------|----------|------|
| 商品名稱 | ✅ 必填 | 顯示於拍賣頁主標題 |
| 商品副標 / 規格 | 選填 | 品牌、型號、顏色、尺寸等簡短說明 |
| 詳細說明 | ✅ 必填 | 商品現況、功能正常與否、外觀瑕疵、附件清單等 |
| 商品數量 | 選填 | 本場拍賣商品件數（預設 1 件）|

#### 商品圖片上傳（至少 1 張）

1. 將圖片直接**拖曳至上傳框**，或點擊「**選擇圖片**」批次選取
2. 支援同時選取**多張圖片**，上傳後顯示縮圖網格
3. **設定封面圖**：點擊任一縮圖 → 點擊「設為封面」，封面圖片會優先顯示於拍賣頁主圖
4. **刪除圖片**：滑鼠移至縮圖 → 點擊右上角「✕」
5. **外部圖片 URL**：點開「外部圖片網址」下拉框，可填入 Imgur / Google Photos 等連結

> ⚠️ **重要**：本地上傳的圖片（Base64 格式）**只儲存在您的裝置**，雲端買家可能無法顯示。  
> 建議將圖片上傳至 **[Imgur](https://imgur.com)**（免費圖床）取得連結後填入外部 URL 欄位。

#### 影音連結（選填）

1. 複製 YouTube 影片的網址（支援一般連結與短網址 youtu.be/...）
2. 貼入「影音連結」欄位，頁面將自動解析並嵌入播放器
3. 可點擊「**預覽**」確認影片是否正確嵌入

### 🅒 區塊 C：競標設定與雙倒數計時模式

#### 價格設定

| 欄位 | 說明 |
|------|------|
| **起標價格** | 拍賣最低起始出價金額（必須 > 0）|
| **最低加價單位** | 每次出標須高於前一標的最低金額（必須 > 0）|

- 輸入框左右附有「**−**」「**+**」按鈕，點擊可快速微調
- **快捷加價預設**：點擊下方快捷晶片（50 / 100 / 200 / 500 / 1000 元）可一鍵套用

---

#### 📅 模式一：固定期限倒數

> 適合「限時拍賣」，在特定截止時間前競標，倒數歸零即結標。

**設定步驟：**
1. 選擇「**固定期限倒數**」模式
2. 設定總倒數時間（天 / 時 / 分 / 秒）
3. 開啟「**防壓標機制**」並設定：
   - **緩衝時間**：倒數剩餘 N 分鐘時觸發（預設 3 分鐘）
   - **延長時間**：觸發後每次延長 N 分鐘（預設 3 分鐘）

**防壓標運作邏輯：**
`
倒數剩餘 3 分鐘 → 有買家出標 → 計時器延長 3 分鐘
→ 重新倒數 3 分鐘 → 又有人出標 → 再延長 3 分鐘
→ 持續直到完整 3 分鐘內無人出標 → 正式結標
`

---

#### 🔄 模式二：24 小時滾動重置

> 適合「開放式長期拍賣」，有人出標就重置計時，完全無壓標壓力。

**運作邏輯：**
`
啟動倒數 24 小時
→ 24 小時內有買家出標 → 計時器重置回 24 小時
→ 持續直到完整 24 小時內完全無人出標 → 正式結標
`

---

### 🅓 區塊 D：取貨方式、保固與條款設定

#### 取貨方式（至少勾選一種）

| 選項 | 說明 |
|------|------|
| 🏠 自取 | 買家親自到指定地點取件 |
| 📦 宅配 / 寄送 | 郵局/宅配到府，可說明運費計算方式 |
| 🏪 超商取貨 | 7-11、全家等超商取貨付款（小件商品適用）|
| ✏️ 自訂 | 可填寫其他取貨說明（如「面交限雙北」）|

#### 保固模式

| 模式 | 適用情境 |
|------|----------|
| **有限保固** | 提供 N 天保固，可設定保固截止時間（預設 3 天至中午 12:00）|
| **現況出售** | 無保固，買家已確認商品狀況 |
| **現場看貨** | 現場測試後成交，成交後不接受退貨 |

#### 預設競標條款（快速勾選）

系統內建三條常用預設條款，**預設全部勾選**：

- ☑️ **48 小時取件**：得標後需於 48 小時內完成付款或取件，逾期視同棄標
- ☑️ **現場測試**：商品於現場看貨測試後成交，不接受退貨
- ☑️ **現況出售**：商品以現況出售，無額外保固承諾

#### 自訂補充條款

在「**自訂補充說明**」文字框中可加入任何補充條款，例如：
- 運費計算方式
- 付款方式（銀行轉帳 / 超商代碼）
- 特殊取件限制
- 商品歷史說明

## 🔍 第三步：驗證、預覽與正式發布

### 資料完整性驗證（系統自動執行）

點擊「**👁 驗證與預覽**」或「**🚀 發布拍賣**」時，系統自動進行以下稽核：

| 驗證項目 | 規則 | 區塊 |
|----------|------|------|
| 賣家名稱 | 不可為空 | 🅐 |
| 商品名稱 | 不可為空 | 🅑 |
| 詳細說明 | 不可為空 | 🅑 |
| 商品圖片 | 至少上傳 1 張 | 🅑 |
| YouTube 網址 | 填寫時需符合有效格式 | 🅑 |
| 起標價格 | 必須大於 0 | 🅒 |
| 加價單位 | 必須大於 0 | 🅒 |
| 取貨方式 | 至少勾選 1 種 | 🅓 |

**驗證未通過時：**
1. 彈出「⚠️ 資料未填寫完整」提示視窗
2. 列出所有未通過的欄位清單（可點擊任一項目跳至該欄位）
3. 關閉視窗後自動平滑滾動至**第一個問題欄位**並加上紅色高亮動畫

---

### 買家視角模擬預覽

點擊「**👁 預覽**」後進入全螢幕預覽模式：

- **📱 手機版**：模擬 iPhone 寬度（390px）的買家視角
- **💻 電腦版**：模擬 900px 寬度的桌面瀏覽器視角
- 預覽內容：導覽列、圖片輪播（可滑動）、倒數計時環、競標資訊、保固說明、條款確認
- **模擬出標**：可點擊「🔨 模擬出標」體驗完整的競標條款確認流程
- **確認發布**：在預覽頁面確認無誤後，點擊「**✅ 確認並正式發布**」

---

### 正式發布與 QR Code 生成

點擊發布後，系統依序執行：

1. **資料收集**：整合所有區塊設定，初始化競標狀態
2. **☁️ 雲端上傳**（若已連線 Firebase）：
   - 生成唯一 **Auction ID**（格式：AUC-XXXXXXXX-XXXX）
   - 將商品資訊、競標設定、計時器參數上傳至 Firebase
3. **🔗 網址生成**：
   - 雲端模式：https://[你的網域]/index.html?id=AUC-XXXXXXXX-XXXX
   - 本機模式：https://[你的網域]/index.html?auction=1&title=...
4. **📱 QR Code 生成**：自動根據網址繪製可掃描的 QR Code 圖片
5. **🎊 發布成功**：顯示成功動畫，系統自動滾動至分享區

**分享區操作：**
- 🔑 點擊 **Auction ID** 晶片 → 複製 ID
- 📋 點擊「**複製**」→ 複製完整網址
- ⬇️ 點擊「**下載 QR**」→ 下載 QR Code 圖片（可貼至 IG 限時動態、YouTube 直播畫面）
- 📤 點擊「**分享連結**」→ 使用手機原生分享功能（僅手機支援）

## 🏆 第四步：買家競標操作流程

買家透過 **QR Code** 掃碼或點擊**分享連結**進入拍賣頁面：

### 頁面載入
- 系統自動從 Firebase 讀取拍賣資料（顯示「☁️ 正在載入拍賣資料…」）
- 載入完成後顯示商品詳情、即時倒數與目前最高出標

### 商品瀏覽
- **圖片輪播**：點擊箭頭或手指左右滑動切換圖片，下方縮圖列可直接點選
- **影片播放**：點擊即可在頁面內播放 YouTube 影片
- **詳細說明**：向下滾動查看完整商品描述與條款

### 登入競標
1. 在登入區輸入**帳號 / 暱稱**（無需密碼或實名）
2. 點擊「**✅ 登入**」
3. 登入成功後顯示目前帳號與「登出」按鈕

### 出標流程
1. 在金額輸入框填入出標金額（不可低於最低出標金額）
2. 或使用快捷加價按鈕（+1倍 / +2倍 / +5倍 加價）
3. 點擊「**🔨 我要出標**」按鈕
4. 彈出競標條款確認視窗，勾選**所有條款**後點擊「**✅ 確認競標**」

### 即時同步（Firebase 雲端模式）
- 任一買家出標成功後，**所有在線買家畫面即時更新**（不需重新整理）
- 底部狀態欄顯示：雲端連線狀態、總出標筆數
- 顯示即時線上觀看人數

### 拍賣結束
- 倒數歸零時顯示「**拍賣結束**」
- 若有得標者：顯示得標者暱稱與最終得標金額，播放得標動畫
- 若無人出標：顯示「⏰ 拍賣結束，無人出價」

## 💾 資料備份與匯出 / 匯入（I/O 工具列）

頁面底部提供完整的資料管理工具列：

| 按鈕 | 功能 |
|------|------|
| 💾 **儲存目前所有設定** | 將四個區塊所有設定存入瀏覽器 localStorage（即時自動備份）|
| 📤 **匯出 A** | 將區塊 A（賣家資訊）匯出為 JSON 檔案 |
| 📤 **匯出 B** | 將區塊 B（商品資訊）匯出為 JSON 檔案 |
| 📤 **匯出 C** | 將區塊 C（競標設定）匯出為 JSON 檔案 |
| 📤 **匯出 D** | 將區塊 D（取貨條款）匯出為 JSON 檔案 |
| 📤 **全部匯出** | 匯出包含四個區塊的完整 JSON 備份 |
| 📥 **匯入** | 選取先前匯出的 JSON 備份，自動還原所有設定 |

> 💡 **建議**：每次拍賣前先「全部匯出」備份一份，避免瀏覽器清除快取後設定遺失。

### 分區重置

每個區塊右上角都有「**↺ 重置**」按鈕，可清除該區塊設定並還原為預設值（其他區塊不受影響）。

## ❓ 常見問題 Q&A

**Q：不設定 Firebase 還能使用嗎？**  
A：可以！系統在本機模式下完整運作，所有功能正常。但生成的網址只有同一台裝置瀏覽器才能開啟，無法讓其他買家跨裝置即時競標。

**Q：Firebase 免費方案會有使用限制嗎？**  
A：Firebase Spark（免費）方案提供每月 **10 GB 下載量**與 **1 GB 儲存空間**，對一般拍賣場次完全足夠。同時上線的連接數無嚴格限制。

**Q：買家看不到商品圖片怎麼辦？**  
A：本地上傳的圖片以 Base64 格式儲存在賣家裝置，不會上傳至 Firebase。請將圖片先上傳至 [Imgur](https://imgur.com)（免費圖床），取得圖片連結後填入「外部圖片網址」欄位，確保所有買家都能看到圖片。

**Q：如何在 YouTube 直播中分享拍賣連結？**  
A：  
1. 在直播說明欄位貼上拍賣網址  
2. 在直播聊天室置頂您的拍賣連結  
3. 截圖 QR Code 圖片並在直播畫面角落展示  
4. 觀眾掃碼即可直接進入競標頁面

**Q：如何在 IG / TikTok 分享？**  
A：  
- **IG**：Bio 連結填入拍賣網址；限時動態展示 QR Code 圖片並加入連結貼紙  
- **TikTok**：個人簡介加入連結；直播時口頭說明並在畫面展示 QR Code  
- **蝦皮 / 露天**：在商品描述或公告欄貼上拍賣連結與 QR Code 圖片

**Q：拍賣結束後 Firebase 資料還在嗎？**  
A：Firebase 資料庫的資料會一直保留，不會自動刪除。若需清除，可至 Firebase Console → Realtime Database 手動刪除對應的 Auction ID 節點。

**Q：可以在手機上操作賣家後台嗎？**  
A：可以。系統完全支援手機操作，所有按鈕均針對觸控加大設計，圖片上傳也支援直接從手機相簿選取。

**Q：發布後想修改商品資訊怎麼辦？**  
A：目前需要返回管理後台修改後重新發布（會生成新的 Auction ID 與新的網址），原有的出標紀錄不會延續。建議在發布前先使用「預覽」功能仔細確認。
